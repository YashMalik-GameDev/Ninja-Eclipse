# Ninja Eclipse

> A 2D action platformer built in Unity as part of my game development portfolio.

## About

Ninja Eclipse is an original 2D action platformer where the player controls a lone ninja navigating through a dark, moonlit world filled with enemies, hazards, and platforming challenges.

This project is being developed from scratch to strengthen my Unity gameplay programming and game architecture skills. The gameplay is prototyped using placeholder shapes before replacing them with original low-poly assets created in Blender.
